# Design — Spirit Start

Material completo para o redesign visual do app (tema "Amanhecer").

| Arquivo | O que é |
|---|---|
| [`especificacao-kiro.md`](especificacao-kiro.md) | **Especificação completa para o Kiro**: diagnóstico, tokens de cor prontos, direção de arte, mudanças por tela, plano de implementação e critérios de aceitação |
| [`mockups.html`](mockups.html) | Mockups visuais: login (antes/depois), dashboard e lição no novo tema |
| [`pesquisa-e-referencias.md`](pesquisa-e-referencias.md) | Pesquisa e evidências: paletas de apps de fé/meditação, padrão Duolingo, acessibilidade WCAG, fontes |
| [`backgrounds/login-amanhecer.svg`](backgrounds/login-amanhecer.svg) | Arte final do background da tela de login — luz de Deus Pai atravessando nuvens no amanhecer (fonte vetorial 1080×1920) |

**Resumo da direção:** trocar o tema escuro/dourado por céu claro do amanhecer com nuvens macias,
mantendo o dourado apenas como acento (CTA, XP, conquistas). Regra 60/30/10, contraste WCAG AA
verificado, sem mudanças de lógica ou navegação.
